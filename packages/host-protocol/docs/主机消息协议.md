# 主机消息协议（Host Protocol）

| 模块 | 方向 | 目标 | Topic 规范（MQTT 风格） | Message.type | 说明 |
|---|---|---|---|---|---|
| 注册 | Host → Manager | 上报主机信息/能力树 | `host/{hostId}/up/register` | `register` | 主机上线后首次上报 |
| 心跳 | Host → Manager | 上报在线与基础状态 | `host/{hostId}/up/heartbeat` | `heartbeat` | 定时上报 |
| 配置变更 | Host → Manager | 上报配置变更结果/通知 | `host/{hostId}/up/config.changed` | `config.changed` | 主机侧配置被修改 |
| 远控结果 | Host → Manager | 上报远控调用结果 | `host/{hostId}/up/control.result` | `control.result` | 执行成功/失败 |
| 消息转发 | Host → Manager | 通过管理端中继消息 | `host/{hostId}/up/relay` | `relay` | 由 Host 发起转发 |
| 配置查询 | Manager → Host | 远程读取配置 | `host/{hostId}/down/config.get` | `config.get` | 管理端读取配置 |
| 配置下发 | Manager → Host | 远程设置配置 | `host/{hostId}/down/config.set` | `config.set` | 管理端设置配置 |
| 配置查询结果 | Host → Manager | 返回 config.get 结果 | `host/{hostId}/up/config.get.result` | `config.get.result` | 用 `sid` 关联请求 |
| 配置下发结果 | Host → Manager | 返回 config.set 结果 | `host/{hostId}/up/config.set.result` | `config.set.result` | 用 `sid` 关联请求 |
| 远程控制 | Manager → Host | 调用主机能力方法 | `host/{hostId}/down/control.invoke` | `control.invoke` | 管理端发起远控 |
| 消息转发 | Manager → Host | 将中继消息投递到目标主机 | `host/{hostId}/down/relay` | `relay` | 由 Manager 发起投递 |
| 通用请求 | Manager → Host | 通用 request（RPC） | `host/{hostId}/down/rpc.request` | `rpc.request` | 用 `sid` 关联响应 |
| 通用响应 | Host → Manager | 通用 response（RPC） | `host/{hostId}/up/rpc.response` | `rpc.response` | `ok/result/error` |

## 1. 为什么

- 需要在 Host 与 Host Manager 之间建立一套可插拔传输层（MQTT/UDP/WebSocket 等）之上的统一消息结构
- 需要覆盖三类能力：远程配置、远程控制、跨网络消息转发

## 2. 是什么

- Topic：用于路由消息到指定主机及方向（up/down）
- Message：统一 JSON Envelope，以 `type` 区分业务动作，以 `payload` 承载数据

## 3. 怎么做

### 3.1 Topic 约定

| 名称 | 值 | 用途 |
|---|---|---|
| 根 Topic | `host` | 统一前缀 |
| Host 上行 | `host/{hostId}/up/{type}` | Host → Manager |
| Host 下行 | `host/{hostId}/down/{type}` | Manager → Host |
| 监听所有上行 | `host/+/up/#` | Manager 侧订阅 |
| 监听所有下行 | `host/+/down/#` | Host 侧订阅 |

### 3.2 Message 统一字段

| 字段 | 类型 | 必填 | 说明 |
|---|---:|:---:|---|
| `type` | string | 是 | 见下方枚举 |
| `timestamp` | number | 否 | 毫秒时间戳（建议必填） |
| `ts` | number | 否 | 兼容字段：同 `timestamp` |
| `tid` | string \| number | 否 | 事务标识：多个事件可共享同一 `tid` |
| `sid` | string \| number | 否 | 序列标识：用于 request/response 关联 |
| `from` | string | 否 | 发送方标识（建议必填） |
| `to` | string | 否 | 接收方标识（建议必填） |
| `payload` | object | 是 | 业务数据 |

### 3.3 上行消息（Host → Manager）

#### a) register

```json
{
  "type": "register",
  "timestamp": 1710000000000,
  "from": "host-1",
  "to": "manager",
  "payload": {
    "id": "host-1",
    "name": "demo-host",
    "tree": {
      "id": "host-1",
      "capabilities": []
    }
  }
}
```

#### b) heartbeat

```json
{
  "type": "heartbeat",
  "timestamp": 1710000000000,
  "from": "host-1",
  "to": "manager",
  "payload": {
    "id": "host-1",
    "status": {
      "uptime": 12345
    }
  }
}
```

#### c) config.changed

```json
{
  "type": "config.changed",
  "timestamp": 1710000000000,
  "from": "host-1",
  "to": "manager",
  "payload": {
    "path": "network.host",
    "value": "10.0.0.2"
  }
}
```

#### d) control.result

```json
{
  "type": "control.result",
  "timestamp": 1710000000000,
  "from": "host-1",
  "to": "manager",
  "tid": "tx-10001",
  "sid": "req-90001",
  "payload": {
    "capability": "system",
    "method": "reboot",
    "ok": true,
    "result": {
      "accepted": true
    }
  }
}
```

#### e) relay

```json
{
  "type": "relay",
  "timestamp": 1710000000000,
  "from": "host-1",
  "to": "manager",
  "payload": {
    "from": "host-1",
    "to": "host-2",
    "topic": "peer/chat",
    "payload": {
      "text": "hello"
    }
  }
}
```

#### f) config.get.result

```json
{
  "type": "config.get.result",
  "timestamp": 1710000000000,
  "from": "host-1",
  "to": "manager",
  "tid": "tx-10002",
  "sid": "req-90002",
  "payload": {
    "path": "network",
    "ok": true,
    "value": {
      "host": "10.0.0.2"
    }
  }
}
```

#### g) config.set.result

```json
{
  "type": "config.set.result",
  "timestamp": 1710000000000,
  "from": "host-1",
  "to": "manager",
  "tid": "tx-10003",
  "sid": "req-90003",
  "payload": {
    "path": "network.host",
    "ok": true
  }
}
```

#### h) rpc.response

```json
{
  "type": "rpc.response",
  "timestamp": 1710000000000,
  "from": "host-1",
  "to": "manager",
  "tid": "tx-10004",
  "sid": "req-90004",
  "payload": {
    "name": "system.ping",
    "ok": true,
    "result": {
      "ms": 12
    }
  }
}
```
